# Security Policy

## Supported Versions

Security fixes are provided for the latest version available on the `main` branch. Older commits and forks may not receive security updates.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately. On GitHub, use the repository's **Security** tab and choose **Report a vulnerability** to create a private vulnerability report. Do not open a public issue or pull request containing exploit details.

If private vulnerability reporting is unavailable, contact a repository maintainer through the contact details on their verified GitHub profile and ask for a private channel. Share only the information needed to reproduce and assess the issue.

Please include the affected component or commit, impact, reproduction steps, and any suggested mitigation. The maintainers will acknowledge the report, investigate it, and coordinate a fix and disclosure timeline with you. Please allow maintainers a reasonable opportunity to address the issue before public disclosure.
